# 分析报告撰写框架

本文件供 WorkBuddy 在阶段 B 撰写 `insights.md` 时读取。目标是产出**可回溯到原文、不下诊断、不臆造**的观察，而非人格判定。

## 一、解读稿结构

按以下顺序写 Markdown，六个维度各一节，加两节收尾：

```
## 价值观与取舍
（3–5 句，关键句标注题号，如「在 Q1 里……」）

## 自我认知
……

## 情感与关系
……

## 审美与趣味
……

## 向往与可能
……

## 时间与记忆
……

## 张力与对照
（指出 1–2 处答案之间的呼应或不一致，只描述现象，不判断好坏）

## 总体侧写
（一段 120–200 字的收束，用「在这份答案里」开头，避免定性标签）
```

**格式约束**：解读稿只使用 `## / ###` 标题、普通段落、无序列表（`-`）与有序列表（`1.`）；不要使用表格、HTML 标签或代码块——报告渲染器只识别上述四种语法，表格会原样显示竖线。

## 二、六个维度的观察角度

| 维度 | 观察什么 | 避免什么 |
| --- | --- | --- |
| 价值观与取舍 | 快乐与成就的定义偏向内在体验还是外部认可；对遗憾、痛苦的表述尺度；座右铭与实际回答是否呼应 | 不评价价值观高下 |
| 自我认知 | 自我描述的具体程度；是否允许自己有缺点；对「改变」的想象指向能力还是关系 | 不推断自尊水平、不给自信打分 |
| 情感与关系 | 答案里出现的是人、物件还是场景；关系中被看重的品质是稳定、坦诚还是默契 | 不推断依恋类型、不评价人际关系质量 |
| 审美与趣味 | 偏好的媒介类型（书 / 音乐 / 影像 / 食物 / 地点）；答案偏向作品名还是偏向当时的场景与人 | 不推断品味层级、不做阶层化描述 |
| 向往与可能 | 想拥有的才华与想成为的人之间的差距；理想生活是具体地点还是抽象状态 | 不评判「理想是否现实」、不做职业建议 |
| 时间与记忆 | 幸福时刻的时间指向（过去 / 当下 / 未来）；对自由时间的真实用法；对终点的表述方式 | 不推断生死观深浅、不做心理风险判断 |

## 三、措辞清单

**推荐**：倾向于 / 在回答中多次出现 / 似乎更常提到 / 与 Qx 形成呼应 / 这份答案里 / 值得注意的是 / 相对地 / 未作回答

**禁用**：你是一个……的人 / 本质上 / 说明你…… / 典型的内向（外向）型 / MBTI / 九型人格 / 得分 / 评级 / 心理健康 / 焦虑 / 抑郁 / 创伤 / 缺陷 / 建议你应该…… / 显然 / 无疑 / 一定

## 四、张力与对照怎么找

只从以下可核对的现象里挑，最多两条：

- 同一维度内两题的取向差异（例如 Q25 向往的才华与 Q26 喜欢的工作方式并不一致）；
- 跨维度的重复意象（某个地点、某个人、某种状态在多个维度里反复出现）；
- 具体与抽象的反差（部分答案落到人名地名，部分答案停留在抽象词）；
- 时间指向的错位（最幸福的时刻在过去，最想成为的人指向未来）。

写法示例：「Q31 把幸福落在一次具体的、过去的场景，Q29 对『想成为什么样的人』则使用了抽象描述；两处的时间指向不同，但没有哪一处更『真实』。」

不要写成「说明你其实更怀念过去」这类推断。

## 五、缺失答案处理

- 未作答或写「暂无 / 不方便回答」的题，只在「未作答清单」中列出，不进入解读。
- 某维度作答少于 2 题时，该维度小节写一句「本维度作答较少，仅做原文呈现」即可，不要强行归纳。
- 整体完成度低于 30% 时，省略「张力与对照」与「总体侧写」，只保留事实描述。

## 六、边界声明

普鲁斯特问卷是文学性的自我问答传统，**不是心理测评量表**。报告不产生分数、类型、诊断或专业建议，不构成医疗、法律、投资、人事决策依据。涉及重大个人决策时，应咨询具备资质的专业人士。

不得因用户要求而放宽上述边界；用户明确要求人格判定或量表化结论时，礼貌说明限制并提供基于原文的观察版本。
